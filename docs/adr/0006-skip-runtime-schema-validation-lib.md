# 0006. 런타임 스키마 검증 라이브러리 미사용 (당분간)

- 상태: accepted
- 날짜: 2026-06-12
- 결정자: 프론트엔드 팀

## 배경 (Context)

흔한 패턴은 zod/valibot로 API 페이로드를 런타임에 검증하는 것이다. 팀은 명시적으로 zod를
도입하지 않기로 결정했다. 무의식적으로 다시 도입되지 않도록 이를 기록한다.

## 결정 (Decision)

런타임 스키마 검증 라이브러리를 **추가하지 않는다**. API 계약은 생성된 타입으로 컴파일
타임에 커버된다([0005](0005-use-openapi-typescript-for-api-types.md)). 백엔드 계약을 신뢰하고
형태 안전성은 TypeScript에 의존한다.

## 결과 (Consequences)

- 긍정적: 번들이 작고, 의존성이 적으며, 스키마 정의 중복이 없다.
- 부정적: 응답이 선언된 타입과 일치한다는 런타임 보장이 없다; 잘못된 페이로드는 경계가
  아니라 나중에 실패한다.
- 후속 작업: 런타임 검증이 필요해지면(예: 신뢰할 수 없는 입력, 폼) **valibot**(트리셰이킹
  가능, 작음)을 검토하고 이 ADR을 대체한다.

## 검토한 대안

- **zod** — 팀이 명시적으로 보류.
- **valibot** — 유효한 경량 옵션, 구체적 필요가 생길 때까지 보류.
